MCMC sampling

Wren currently ships with two very simple samplers.

Results are stored as FlexiChain{VarName}; please see the FlexiChains documentation for more information.

using Wrenusing Distributionsusing LinearAlgebra: Iy = [28, 8, -3, 7, -1, 1, 18, 12]sigma = [15, 10, 16, 11, 9, 11, 10, 18]J = 8@wren function eight_schools(y, sigma, J)    mu ~ Normal(0, 5)    tau ~ truncated(Cauchy(0, 5); lower=0)    theta ~ MvNormal(fill(mu, J), tau^2 * I)    for i in 1:J        @observe y[i] ~ Normal(theta[i], sigma[i])    end    return (mu=mu, tau=tau)endmodel = eight_schools(y, sigma, J)

No U-Turn Sampler (NUTS) for a Wren model. All dynamichmc_kwargs are passed to DynamicHMC.mcmc_with_warmup, allowing you to customise the warmup and sampling behaviour.

source
