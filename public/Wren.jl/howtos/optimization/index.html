Point estimates

Load Optimization.jl and a solver package to find a maximum a posteriori (MAP) estimate:

using Wrenusing Wren.Dists: Gamma, Poissonusing OptimizationOptimJL: LBFGSimport Enzyme, Optimization@wren function poisson_rate(count)    rate ~ Gamma(2.0, 1.0)    @observe count ~ Poisson(rate)endmodel = poisson_rate(3)fit = Wren.optimize(model, LBFGS())

The fitted parameters are returned as a VarNamedTuple; here the MAP estimate of rate is approximately 2:

fit.params
VarNamedTuple
└─ rate => 1.9999999997152438

Use lp_function=loglikelihood for maximum likelihood (MLE):

fit = Wren.optimize(model, LBFGS(); lp_function=loglikelihood)fit.params
VarNamedTuple
└─ rate => 2.99999999807544

Both methods optimise within the parameter support declared by the model's priors. Parameters use unconstrained coordinates internally, but the objective is the original-space density without a change-of-variables Jacobian. Solver keywords are passed to Optimization.solve; check fit.solution.retcode before using an estimate.

Convenience functions

MAP selects lp_function=logjoint, as in the first example. MLE selects lp_function=loglikelihood, as in the second:

map_fit = MAP(model, LBFGS())mle_fit = MLE(model, LBFGS())(map=map_fit.params, mle=mle_fit.params)
(map = VarNamedTuple(rate = 1.9999999999994478,), mle = VarNamedTuple(rate = 2.9999999999995914,))

Both helpers fix the objective and forward all other keywords to optimize, including initialisation and solver options. Use optimize for a custom objective.

Initialisation

By default, optimisation starts from a draw from the model's priors. Use latent_source to provide an initial state, as for VecModel:

initial = FromValues(VarNamedTuple(rate=1.5))fit = Wren.optimize(model, LBFGS(); latent_source=initial)fit.params
VarNamedTuple
└─ rate => 2.000000003330287

Direct log-density access

For direct control, logdensity constructs the same VecModel using the LogDensityProblems.jl interface:

import LogDensityProblems as LDPdensity = logdensity(model, AutoEnzyme(; mode=Reverse); latent_source=initial)x = vectorise_latents(initial, density)LDP.logdensity(density, x)LDP.logdensity_and_gradient(density, x)
(-2.7644339286872324, [2.0])

The default is the unnormalised posterior density in unconstrained coordinates, including the Jacobian used by samplers. For a custom optimisation problem, pass lp_function=logjoint for the original-space MAP objective or lp_function=loglikelihood for MLE. Omit the AD backend when only density values are needed. This interface does not require Optimization.jl.
