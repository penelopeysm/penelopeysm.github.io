Loading PosteriorDB models

Wren (technically, WrenCore) provides a PosteriorDB extension where some PosteriorDB models are available for use. (Not all have been added yet, but the intent is that Wren will eventually provide a complete collection.)

To list the available models, use:

using Wren, PosteriorDBavailable_posteriordb_models()
10-element Vector{String}:
 "GLMM_Poisson_data-GLMM_Poisson_model"
 "GLM_Binomial_data-GLM_Binomial_model"
 "GLM_Poisson_Data-GLM_Poisson_model"
 "Mh_data-Mh_model"
 "Rate_1_data-Rate_1_model"
 "arK-arK"
 "eight_schools-eight_schools_centered"
 "gp_pois_regr-gp_regr"
 "kidiq-kidscore_interaction"
 "sblri-blr"
Benchmarks

These PosteriorDB models are also benchmarked in order to track performance over time: see https://pysm.dev/Wren.jl/bench.

And to load one of these:

model = posteriordb_model("eight_schools-eight_schools_centered")
Model eight_schools_centered
├─ arguments
│  ├─ y => [28, 8, -3, 7, -1, 1, 18, 12]
│  ├─ sigma => [15, 10, 16, 11, 9, 11, 10, 18]
│  └─ J => 8
├─ conditioned (none)
└─ expressions
     mu ~ WD.Normal(0.0, 5.0)
     tau ~ WD.HalfCauchy(0.0, 5.0)
     @iid(theta ~ WD.Normal(mu, tau), size = J)
     @batch(name = Symbol("##batch#184"), for i = eachindex(y)
             @observe y[i] ~ WD.Normal(theta[i], sigma[i])
         end)
     return nothing

You can then e.g. sample from this posterior:

using Enzyme # Wren's default AD backend.nuts(model, 1000, 4)

WrenCore.posteriordb_model — Function
posteriordb_model(name::AbstractString) -> WrenCore.Model

Return a Wren model for the PosteriorDB posterior called name, e.g. "arK-arK", using the data from PosteriorDB.

This requires PosteriorDB.jl and WrenDists.jl to be loaded. Only some posteriors are available; an error is thrown for any others, which lists the available ones.
