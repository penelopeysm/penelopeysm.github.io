Multivariate

WrenDists.MvNormalScale — Type
MvNormalScale(μ, L)

Multivariate normal distribution with mean vector μ and scale factor L, where L can be a lower-triangular matrix, a Diagonal, or a UniformScaling.

Warning

This differs from Distributions.jl which uses the covariance matrix Σ instead of the scale factor L. The relationship is Σ = L * L'. The intention of this is to avoid the need to compute the Cholesky factor of Σ inside the model when it is already known, which is often the case with standard deviations that are constant.

In particular, if the covariance matrix is diagonal, then L is simply the vector of standard deviations (rather than variances, as in Distributions.jl).
